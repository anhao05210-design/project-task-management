# Orbit 项目任务管理

一个可直接在浏览器打开的轻量项目看板演示，适合团队体验任务分配、状态流转和迭代进度管理。

## 使用

直接打开 `index.html`。可以在侧边栏切换项目、创建项目，查看“我的任务”和待处理任务收件箱；在看板与列表视图间切换，按标题、描述、负责人或标签搜索，并按负责人筛选。点击任务卡片可调整状态、负责人、优先级和标签；看板菜单支持排序、清除筛选和导出当前任务 CSV。所有改动自动保存在当前浏览器；点击顶部重置按钮可恢复初始示例数据。

## 数据说明

这是本地交互演示，没有账号、云端同步或多人协作。数据仅保存在当前浏览器的 localStorage 中，不要填写真实客户信息或公司敏感数据。
